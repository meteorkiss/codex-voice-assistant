# Codex 语音助手 · 声伴

当前开发版 **v6 / 0.6.17**。双击 **声伴.exe**，桌面显示透明声波。右键声波打开设置；也可以点击右下角的声伴托盘图标。当前本机完整目录已经包含所需的语音运行环境，不需要另配 Python；Git 源码不含该运行环境，准备方式和未完成项见[依赖与源码交付](docs/依赖与源码交付.md)。

项目整理（2026-09-10）：[功能总表](docs/功能总表.md) · [架构设计](docs/架构设计.md) · [开发规范](docs/开发规范.md) · [实施与验收计划](docs/实施与验收计划.md)。这些文档记录 0.6.12 的现状和后续改造方案，不代表规划功能已上线。

0.6.17 增加默认关闭的“回答后短时连续接话”。主动开启后，仅当一次唤醒问题已成功发送且对应回答自然朗读完毕，声伴才开放 6 秒接话窗口；一句最长录 30 秒。草稿编辑、目标变化、连接异常、外部麦克风占用、用户结束或闲置都会关闭窗口。短语气词等模糊转写只保留为草稿，不自动派发；这不是可识别电话、电视或所有背景对白的完全免唤醒。

0.6.16 集中管理合成、播放完成与停止清理，合成启动失败和播放失败清理本次临时文件，过期或其它任务的合成结果不播放。停止失败仍取消待播内容，保留正在使用的音频以便再次释放。续读文件拒绝越界路径、目录和重解析点。新增源码依赖检查和 Windows 离线 CI 配置。

0.6.15 将常用设置的语音、设置页和托盘入口接入统一保存与回退逻辑；显示字幕和声波的组合设置一次保存，失败恢复原状态。活动候选操作失败不会变成聊天消息，设置完成也会保留期间出现的新草稿。连接适配层校验请求用途、编号和管理回执，重复成功回执只反馈一次。

0.6.14 拆出配置、发送记录和后台进程管理，保留原配置格式与操作方式。保存失败会清理本次临时文件；进程尚未退出时保留其文件，已启动但回执未确定的发送不重派。程序与启动器统一使用根目录 `VERSION`，构建核对版本说明并在失败时保留原启动器。

0.6.13 统一手动连接、语音切换和新建后连接的校验与失败回退。输入区有草稿时先保留并提示处理；连接期间的新输入、改选、录音、刷新、取消或超时使旧请求失效，重复回执不会重复连接。回归使用独立临时副本，完成后自动清理。

0.6.12 新增本地管理口令：创建和改名分组、移动和改名对话、固定与取消固定、归档其它空闲任务、查看列表与状态、读取回答，以及暂停／继续／重读。唤醒时会保留朗读位置，继续朗读可接着听。操作直接调用本机 Codex 接口，不作为聊天消息发送。完整说法与范围见 [本地管理口令](docs/本地管理口令-0.6.12.md)。

0.6.11 支持单独说“新对话”“新任务”，以及“帮我弄一个新对话”“给我开个新任务”等口语。声伴在发送聊天前匹配完整口令，命中后直接调用创建接口并连接新任务。支持“吧／啊／呀”等句末语气词；讨论关键词、否定句和多个动作仍按普通内容处理。单说“创建”没有指明对象，不作为新建口令。

第一次使用，在设置中刷新本机任务，按目录筛选或直接下拉选择，再点“连接所选任务”。已有设置会恢复到原任务。助手始终绑定明确选择的任务，沿用它在 Codex 中的模型和权限；打开另一个 Codex 任务不会让语音自动换地方。

开启“语音唤醒”后，说 **“你好，声伴”**，听到“在”后说问题。停顿约两秒会自动转写并发送；八秒没有问题则返回待机。需要减少重复唤醒时，可再主动开启“回答后短时连续接话”；窗口中可从字幕按钮、声波右键菜单或托盘选择“结束连续接话”。开始说话、停止朗读、重读和显示字幕也可从托盘或字幕面板到达。

支持六种声波、大小、置顶、可展开的字幕与输入区、七种已核验的微软在线声音，以及 0.8×、1.0×、1.2×、1.5× 语速档位。关闭设置不退出；隐藏只收起声波与字幕，语音按原开关继续。要停止后台运行，请在托盘选择“退出语音助手”。

0.6.2 可直接说“换台湾女声”“语速慢一点”“取消置顶”“显示字幕”等常用口令；声伴在本机修改并保存，不为这些操作向 Codex 发消息。普通问题继续走原任务。完整说法见 [使用说明](docs/使用说明.md)，后续小模型分工和录音边界方案见 [分工方案](docs/语音助手分工方案.md)。

0.6.3 可在声音设置里修改并保存唤醒词、恢复默认；右键声波或使用字幕上的暂停／继续，从原位置接着听。打开设置及刷新任务列表会保留正在朗读的内容。

0.6.5 声波中央提供两个淡色按钮：左侧播放／暂停，右侧结束朗读；取消空格播放快捷键。声波随实际播放和采集音量起伏，暂停后安静下来。开启置顶时，切到其他软件会重新提起悬浮窗，并保持原软件的输入焦点。

0.6.6 可以说“切换到高斯坡建任务”等完整口令，按标题或同音名称查找本机任务，唯一结果实时校验后绑定；多个结果提示选择。附在答案末尾或单独列出的参考链接不再朗读，屏幕上的正文和链接仍保留。完成情况与后续范围见 [功能记录](docs/功能记录.md)。

0.6.7 增加语音新建任务：默认创建独立聊天，明确说“在当前项目新建”才使用当前绑定任务对应的已保存项目。创建并读取校验成功后连接；可说“连接刚才的新任务”或“放弃连接新任务”。结果不确定时不会重复创建，未连接前的新问题保留在输入区，不发给旧任务。新任务使用 Codex 配置的默认模型，不复制原任务的模型设置。

本版也增强了低音量声波的可见变化，实际播放音量不变；唤醒门槛调低后的离线收益和准备空窗见 [唤醒漏检排查](docs/唤醒漏检排查.md)。本机已重新加载 0.6.7 并保留原绑定和偏好；创建功能通过隔离回归，本轮没有真实创建任务或发送测试消息。

0.6.8 修复已退出进程遗留的麦克风会话阻塞声伴监听的问题，并明确显示其他应用占用麦克风的暂停状态。此次唤醒无回应的排查与验证范围见 [排查记录](docs/唤醒无回应排查-20260909.md)。

0.6.9 增加真实采集与模型处理进度检查、有限次数的安全恢复，以及系统默认音频设备变化后的重建。恢复期间保留新回答和文字草稿，原麦克风未释放时不会再开一条输入。本机已加载新版，确认模型处理量持续增长且原绑定和全部偏好保留；实现与验收范围见 [监听健康与恢复](docs/监听健康与恢复-0.6.9.md)。

0.6.10 已补齐创建口令：可以说“创建新任务”“创建一个新任务”“创建新对话”“新开一个对话”“新建一个对话”，支持礼貌前缀、命名及当前项目。直接走声伴本地创建流程；转写原文不改写。复杂多动作句式仍不在此版本范围内。此次音环会动但未唤醒的复查，确认采集与模型处理在前进、没有新唤醒命中；重新加载仅作为恢复尝试，尚未确认真人漏唤醒根因已解决。[本次记录](docs/重复漏唤醒与创建口令-0.6.10.md)

唤醒与语音识别在本机运行。待唤醒音频仅在内存中用于匹配，不保存音频文件；问题录音转文字后清理。台湾女声朗读使用用户已授权的微软在线语音合成，会发送待朗读的答案文字。助手沿用所选 Codex 任务的模型与权限。

本轮外观参考与取舍见 [视觉调整依据](docs/视觉调整依据.md)。开发与验收依据见 [实施框架](docs/实施框架.md)，公开版范围见 [整体方案](docs/公开版整体方案.md)。本机程序与公开发行分开验收；第二台干净电脑、远程任务和模型模式切换仍待后续验证；语音新建的真实创建与连接全过程也尚未作为验收执行。朗读中唤醒的设备支持与实测状态以 [使用说明](docs/使用说明.md) 为准。

请保留整个程序目录，单独复制 exe 无法运行。当前 exe 是无终端的 Windows 启动器，调用本目录内的 PowerShell / WPF 桌面宿主。不要把 `data`、私人任务、音频或发送／创建账本打入公开包。2026-09-12 已从 0.6.16 起将源码上传 GitHub，尚未发布独立安装包；后续按[版本接续](docs/版本接续.md)推进。
