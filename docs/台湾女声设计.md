# 台湾女声设计与接入记录

2026-09-08。目标是用户指定的轻柔、略带撒娇和俏皮的成年台湾女性聊天声。这里的风格只是这套声音的设计要求，不代表所有台湾女性的说话方式。

**当前决定：暂停 Qwen 本地接入。** 实测模型与隔离运行环境合计约 12.10 GB，约十秒样声需 53—59 秒生成。用户认为安装体积过大，并再次明确需要台湾腔，不能只满足普通话甜美女声。下面保留原型记录，后续转查轻量模型或现成在线台湾音色；运行程序仍是原微软方案 0.6.5，未换默认音色、未加入 Qwen 声线。待清理安装缓存约 3.13 GB；清理被自动审批以 `blocked by policy` 拒绝，缓存未删除。

## 查到的能力与边界

现用的微软 Edge TTS 提供晓臻、晓雨等固定音色。接口能调语速、音高和音量，不能接收录音进行音色学习，也不开放任意风格 SSML。因此单独抬高音调不能等同于学会新的聊天语气。[项目说明](https://github.com/rany2/edge-tts)

MiniMax 提供声音设计与参考音频复刻。当前官方列表能核验“甜美女声”等普通话音色，未核验到独立的台湾少女系统音色；名称甜美也不等于台湾口音。它需要另外的账户密钥与在线朗读费用，本轮未调用或发送答案到该服务。[声音列表](https://platform.minimaxi.com/docs/faq/system-voice-id)、[声音设计](https://platform.minimaxi.com/docs/api-reference/voice-design-design)、[官方试听入口](https://www.minimaxi.com/audio)

根据用户“用现成声音，怎么方便怎么来”的要求，本轮只使用已经训练好的 Qwen3-TTS VoiceDesign 模型。以三组声音描述和固定随机种子直接朗读文字，不训练、不微调，也不再下载另一套 Base 模型。三种预设共用同一套模型文件。[官方代码与示例](https://github.com/QwenLM/Qwen3-TTS#voice-design)

模型支持中文和声音描述，但没有“台湾腔一定准确”的保证。发音、轻甜程度、长段阅读是否自然，均需按实际音频验收；不把提示词或营销示例当作听感证明。

## 三版原创方向

| 版本 | 声音设计要求 |
| --- | --- |
| 自然 | 成年女性，台湾华语，放松地交谈，轻柔、有自然停连，适合连续解释事情 |
| 轻甜 | 在自然基础上带笑意、少量轻气声，句尾有柔和起伏，甜度适中 |
| 活泼 | 轻甜基础上稍微俏皮，重音与节奏更灵活，避免每句话都夸张拖长 |

三版使用同一段普通文本，以免靠更换台词混淆声音的实际差异：

> 文件已经保存好了。你先听听看，如果语速太快，我们就慢一点。需要修改的地方，我会一步一步跟你说清楚。

三个预设是已有模型的声音描述选项，并非经过验证的台湾系统声线；不同文本或段落的音色可能波动。试听使用模型生成的声音，不需要收集真人参考录音。

## 本机验证

设备检查为 RTX 3080 Laptop，16 GB 显存、约 64 GB 内存。为避免影响现有语音识别，模型依赖安装在 `runtime/voice-design/venv`。模型文件约 4.52 GB，保存在软件目录中，运行环境额外占用磁盘空间。增加预设只需很小的配置文件；微软在线女声不依赖这套本地模型。安装、来源版本、样声和测量数据保留在 `work/voice-design-prototype`。

三个完整样声和三个唤醒回应均已生成，本机 ASR 核对字词错误率为 0；这不是台湾口音或自然程度的听感证明。用户选中第一版轻甜、第三版自然的试听，缓存分别约 0.56 MB、0.61 MB，但这些小音频不能代替合成新答案所需的模型。原型、准确来源和测量在 `work/voice-design-prototype/metadata.json`。

实验后端的离线测试通过；真实 GPU 测试只到模型加载，随后因就绪校验失败停止，尚未验证真实取消与恢复。实验接线保存到 `work/voice-design-prototype/integration-src`，生产 `Assistant.ps1`、`HandsFree.ps1`、`synthesize.py` 已恢复本轮前的版本。未构建或部署新版本。
