# 声伴 · 视觉调整依据

2026-09-08。根据试用反馈调整：旧声波过于规整，设置窗口的绿色卡片和宣传性文案显得像通用模板。

## 查阅的参考

- [Apple：Motion](https://developer.apple.com/design/human-interface-guidelines/motion)。动效应传达状态、回应操作，简短明确，避免过分抢占注意力。
- [Apple：Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/)。参考连续、及时响应和可中断的运动方式，将交互和视觉一起设计。
- [Apple Music：动态专辑封面准则](https://help.apple.com/itc/albummotionguide/zh_CN.lproj/static.html)。借鉴自然连续的循环、稳定构图和清楚的内容层级。
- [foobar2000：Spectrum Analyzer](https://www.foobar2000.org/components/view/foo_vis_spectrum_analyzer)。参考曲线、径向形式、频段平滑与余辉的表现。声伴当前只有输入音量和对话状态，不能把其动效称为真实频谱分析。
- [Winamp：桌面播放器与可视化](https://support.winamp.com/winamp-desktop-player-for-windows)。了解 AVS、MilkDrop 的可视化用途；桌面助手采用较轻的运动幅度，适合工作时常驻。

## 本轮设计

声波以蓝、青、紫和少量粉色形成连续光泽；默认样式改为多层流动曲线。静止待机也保持微小呼吸，说话时根据实际输入音量产生局部起伏，再平缓收拢。保留透明中心和拖动、右键操作范围。

视觉刷新独立于语音业务计时器，可见时细化动画；隐藏时停止不必要的刷新。朗读和处理中显示各自的状态动画，不宣称音符或频率测量。

设置采用中性色背景、清楚的分隔与少量蓝色强调，分为连接、声音、外观三个页面。删去宣传副标题和大面积绿色装饰。保持任务、声音、唤醒、字幕和窗口操作的已有功能。

六个已有设置编号继续有效，显示名称更新为流光环、柔光环、微粒环、细线环、律动音柱和流动声线。视觉调整不更改已绑定任务、声音或语音发送方式。

## 检查方式

原生渲染检查浅色／深色背景、多个时刻与音量、透明区域、边缘裁切。运行窗口生命周期和设置控制器检查，确认导航、关闭、恢复及已有控件仍可操作；音频采集和发送模块保持现有版本。
