# 声伴本地管理口令 · 0.6.12

先让 Codex 桌面程序保持运行，并在声伴中连接一个本机任务。唤醒声伴后，一次说一个完整口令；也可以在输入区输入口令后点击发送。命中这些口令后，声伴直接调用本机 Codex 的操作接口，不把口令作为聊天消息发送给模型。

**“当前对话”“这个对话”指声伴当前连接的任务。** 即使 Codex 页面已经打开另一个任务，声伴的连接对象也可能仍是原来的任务。操作前可查看声伴当前任务名称。

下面以“周末安排”作为任务的完整名称，以“待办”“工作”作为自定义侧栏分组名称。

| 想做什么 | 可以说 | 实际效果 |
| --- | --- | --- |
| 新建分组 | 新建一个分组叫待办 | 新建自定义侧栏分组；同名分组已存在时提示结果 |
| 新建分组，另一种说法 | 新建一个叫待办的分组 | 同上 |
| 修改分组名称 | 把待办分组改名为工作 | 修改已有自定义分组的名称 |
| 把对话放进分组 | 把这个对话放到待办分组 | 将声伴当前任务移入已有的“待办”分组 |
| 移动指定对话 | 把周末安排任务放到待办分组 | 按完整名称查找任务并移入分组 |
| 修改当前对话名称 | 把当前对话改名为周末安排 | 修改声伴当前任务的标题 |
| 修改指定对话名称 | 把周末安排任务改名为出行计划 | 修改指定任务的标题 |
| 固定对话 | 固定这个对话 | 将当前任务放到侧栏固定区域 |
| 取消固定 | 取消固定这个对话 | 将已固定的任务移回默认任务区域 |
| 打开任务页面 | 打开周末安排任务 | 在 Codex 中打开页面；声伴仍连接原任务 |
| 查询任务状态 | 周末安排任务做完了吗 | 读取当前运行状态，例如正在处理、空闲或未加载 |
| 读取回答 | 读一下周末安排任务的最新回答 | 朗读该任务最近可读取的已完成回答；声伴仍连接原任务 |
| 归档其它任务 | 归档周末安排任务 | 归档指定的空闲任务 |
| 恢复归档任务 | 恢复周末安排任务 | 从归档列表中按完整名称恢复任务 |
| 查看任务名称 | 有哪些任务 | 读取本机任务名称 |
| 查看自定义分组 | 有哪些分组 | 读取已有的自定义侧栏分组名称 |
| 查看项目 | 有哪些项目 | 读取已保存的本机项目名称 |
| 把分组移到上方 | 把待办分组移到最上面 | 将它移到自定义分组的最上方，其余自定义分组保持相对顺序 |
| 删除分组 | 删除待办分组 | 删除这个分组，其中的任务和项目仍然保留 |

“任务”“对话”“聊天”可以用于指代同一种任务对象。固定、取消固定、打开、查询、朗读和改名也可以使用“当前任务”或“这个对话”。

归档和恢复需要操作其它任务：如果目标就是声伴当前连接的任务，请先把声伴切换到另一个任务，再按目标的完整名称操作。任务正在运行或状态无法确认时，声伴会提示等待，不进行归档或恢复。

状态查询反映 Codex 的运行状态。“当前空闲”表示此时没有运行中的处理，不代表声伴已经评估或确认任务目标全部完成。读取回答时，如果接口没有提供完整原文，声伴会提示到 Codex 查看。

**朗读控制**

| 想做什么 | 可以说 |
| --- | --- |
| 暂停当前朗读 | 暂停朗读 |
| 接着朗读 | 继续朗读，或继续读 |
| 从头重读当前任务上一条回答 | 重读上一条回答，或重读上一条 |
| 结束朗读 | 停止朗读 |

重读使用声伴当前连接任务的上一条回答。读取其它任务的回答不会改变这个连接，也不会替换当前任务保存的上一条回答。

**项目和分组的区别**

侧栏分组用于整理显示位置；项目是任务所属的项目。把对话放到“待办分组”不会把它移到某个项目。

如果说“把当前对话放到语音助手项目里”，声伴会在本地识别并提示操作入口，但本版尚未接入项目移动。请在 **Codex 侧栏右键目标对话 → 项目菜单 → 选择目标项目**。Codex 本身可以完成这项移动。

本版没有新增“在任意指定名称的项目里新建任务”、从已有任务分出新任务、任意调整任务顺序等语音功能。已有的“新对话”“帮我弄一个新任务”“在当前项目新建一个任务”和任务切换口令继续使用。

**名称与说法**

按名称操作时，请说任务或分组的完整名称。遇到同名任务，声伴会停止操作，请先在声伴中选中并连接目标，再说“当前对话”；遇到同名分组，请先在 Codex 中改成不同名称。声伴不会猜测“一个任务”“某个对话”“上一个任务”是哪一项。

名称中的全角字符、内部空格，以及“吧”“谢谢”等文字会保留。例如“新建一个分组叫天气吧”会创建名为“天气吧”的分组。如果只是礼貌结尾，可以说“新建一个叫天气的分组吧”。“改名为”后面请直接说完整的新名称。

一次只说一个动作，例如先说“新建一个分组叫待办”，收到结果后再说“把当前对话放到待办分组”。“不要归档这个对话”“新建分组是什么意思”、引用口令或带“然后”的复合句不会触发本地管理操作，保留普通文字处理方式。

声伴会显示操作结果，并在没有新的录音、草稿或任务切换时播报结果。如果提示结果尚未确认，请到 Codex 查看实际状态；声伴不会自动重复执行这次请求。
