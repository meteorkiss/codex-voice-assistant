# 声伴功能总表

更新：2026-09-21。基线：源码 0.6.17。本文统一记录当前能力与后续需求；旧版本方案保留为历史资料，发生状态冲突时先核对生产代码与对应验收记录。

“已实现”只表示进入当前生产路径；隔离测试、真实接口、真人声学和第二台电脑验收分别记录，不能互相替代。0.6.17 已加入可选短时连续接话，十七组离线回归通过；真人声学、背景媒体与第二台电脑仍按各自边界验收。0.6.16 夜间交付状态见[晨间验收](晨间验收.md)。

## 产品范围

Windows 桌面语音助手：负责听取用户输入、直接执行明确的软件操作、连接用户选择的 Codex 任务，以及显示和朗读结果。普通问题保留转写原文，由绑定任务处理。桌面当前打开的任务与声伴绑定任务是两个状态，不能自动等同。

## 已实现的能力

2026-09-21 收口审核：用户确认连续两轮已发送文字清空、安静退出后唤醒正常，并总体认可本轮测试。手机视频误收发生且被用户暂时接受，不计防误收通过；长句计时、设备和异机仍不追加未取得的证据。详见[0.6.17 审核](审核-0.6.17.md)。历史组合测试与生成物受阻事项未豁免，暂未正式收口。

2026-09-21 接话回归：正常发送的 pending 账本不再误取消同一接话请求；必须匹配仍运行的进程、请求/目标/代次/原文才等待成功回执并清除对应旧句。结果未知、取消或新输入仍保护、不重派。两轮接话隔离链路已补测；真人接话因本次故障重新列为待复验。用户已确认的重开恢复、普通唤醒和任务切换不重复整套验收。

2026-09-21 连接回归：修复独立启动依赖旧 Codex 进程参数发现连接的问题；同句柄校验本机 Codex 包身份/会话及工具能力，唯一端点才连接。启动恢复上次成功目标，临时未就绪有限只读重试；不随机代选、不重复发送。设置页与诊断区分目标读取、本地记录和保存错误。当前仅核验本机 Store 分发版，详见版本接续与本轮验收。

2026-09-13 本地候选确认增量：用户授权先采用本地方案，N12 小模型仍未实施。按空格/中英文字边界/版本分关键词，不做任意中文语义分词；各词必须匹配。英文四字母起的有限拼写相似、三汉字起的同音及既有产品别名只给候选，唯一字面匹配才直接连接。单候选问“是不是”，沿用唤醒后“是的/不是”；多候选用编号，不猜数字、不自动跟随 Codex 页面、不新增持续录音或依赖。

| 编号 | 功能组 | 当前能力 | 边界与证据 |
| --- | --- | --- | --- |
| F01 | 桌面入口 | 六种透明声波、拖动、大小、置顶、托盘、隐藏恢复、设置和字幕 | 隐藏不退出，设置关闭不退出；外观和控制器已有测试 |

| F03 | 朗读输出 | 在线声音、语速、试听、自动朗读、暂停、继续、重读、停止、非语音内容过滤 | 完整文字保留；在线合成会发送待朗读文字；本地声音实验未进入生产路径 |
| F04 | 唤醒与续读 | 播放中唤醒交接、保存音频位置与剩余队列、续读、旧书签失效清理 | 0.6.12 生产函数隔离测试通过；不能据此承诺真人唤醒成功率或跨设备无缝续播 |
| F05 | 设置口令 | 声音、语速、样式、置顶、字幕、显示与自动朗读等 | 完整明确口令在本机执行；0.6.15 常用设置共用保存与回退，保留新草稿；普通讨论与否定不触发操作 |
| F06 | 任务绑定与切换 | 列表同步侧栏名称、目录筛选、明确绑定、标题关键词组合及有限同音搜索、候选选择 | 0.6.17 修复首句冒充标题；支持“声伴 6.17”“高斯泼溅”等关键词，版本边界不猜；候选仍须实时校验，缺少标题覆盖会提示；实际加载状态见晨间验收 |
| F07 | 任务创建 | 独立任务、可选标题、显式当前项目、创建后校验绑定、恢复或放弃连接 | 创建只派发一次；临时编号不能当真实任务编号；完整真实链路仍需补验 |
| F08 | 任务管理 | 改名、移入分组、固定与取消固定、打开、归档与恢复 | 名称操作不猜重名；归档与恢复只允许其它空闲或未加载任务 |
| F09 | 分组管理 | 新建、改名、删除、自定义分组置顶 | 删除分组保留其中内容；已做临时空分组创建、改名、删除实测并清理 |
| F10 | 列表与读取 | 任务、分组、项目列表；指定任务状态与最近已完成回答 | 打开或朗读另一任务不改变绑定；空闲不等于工作目标已完成 |
| F11 | 回执与持久化 | 发送、创建、管理请求账本，防重派，未知结果保留，偏好保存 | 结果未知不自动重试；迟到结果不能覆盖后来的草稿和任务 |
| F12 | 监听健康 | 采集与模型进度检查、有限恢复、设备路由变化处理、外部麦克风提示 | 本机已有运行健康记录；睡眠、插拔和真人长时间使用仍需系统验收 |
| F13 | 短时连续接话 | 默认关闭；唤醒问题的回答自然朗读后等待 6 秒，单句最长 30 秒；可显式结束 | 草稿、目标、连接、外部麦克风或迟到回调使窗口失效；模糊转写不自动派发；不等同完全免唤醒 |

0.6.17 设置交互增量（2026-09-13）：选中目标后自动校验并连接，不再需要连接按钮；程序刷新/筛选不代替用户选任务，失败回显原实际连接，快速改选后旧回执失效。设置面板不置顶；悬浮声波和字幕仍按原偏好置顶。源码验证、实际加载及微信截图现场确认分开记录。

同日用户已确认手动选任务、下一句语音进入所选目标、微信截图通过。截图暴露的“把任务切到这个申办0.6.17”“把任务切到6.117”另作语音回归：增加对象前置的本地口令入口；版本限定的已知产品别名在字面匹配后尝试，绝不把 6.117 推断成 6.17。无匹配显示并播报实际查询、保留原连接；本增量不是新增语音大模型或页面自动同步。

0.6.17 归档恢复增量：当前目标每 5 秒由独立只读检查确认状态；归档/缺失时普通发送停用，保留原真实编号作本地操作上下文，不自动选其它任务。已有草稿先保存到 `data/recovery-drafts` 后移出操作输入；用户明确选择新目标时也采用同样保护。保存失败不清原文，新目标不会自动恢复/发送旧草稿。恢复期间唤醒及本地切换仍可用，普通语音只存草稿。状态未知不猜归档；发送边界再次校验，跨进程检查与实际派发不是原子事务。源码验证和实际加载见晨间验收。

当前口令见[本地管理口令](本地管理口令-0.6.12.md)，0.6.12 的证据及边界见[本版验证](本地管理实现与验证-0.6.12.md)。
