## 现场体验

1. 正常唤醒，问一句简短问题，确认文字与朗读正常。
2. 分别在设置页和通过语音改变语速或置顶，确认状态一致。
3. 朗读中暂停、继续、停止，确认停止后不再串出旧语音。
4. 输入一段草稿，再进行任务选择或设置操作，确认草稿保护符合提示。
5. 按实际需要选择目标任务，确认后续问题投递准确。
