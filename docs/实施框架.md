## 使用方式

启动后桌面只显示透明声波。左键拖动，右键设置置顶、打开设置、显示字幕、停止朗读或隐藏声波。隐藏不退出，托盘负责恢复、设置与退出。声音与模型分开：Codex 中绑定任务的模型继续思考和工作，声伴负责听、显示和朗读。

首次进入设置，刷新本机候选任务，可按目录筛选并在下拉框选择，确认连接后才允许发送。已有绑定继续恢复；候选或连接失效时提示修复，不自动换到另一个任务。工作目录筛选不移动任务文件。

## 模块与边界

| 模块 | 责任 | 接口与约束 |
| --- | --- | --- |
| 桌面宿主 | 透明声波、独立设置与字幕、托盘、位置和窗口生命周期 | 六种内置样式，共享音量和状态；普通界面操作不断读；退出统一释放资源 |
| 对话协调器 | 待机、唤醒、录音、识别、发送、等待、朗读及取消 | 唯一状态管理；识别与合成结果带代次；换任务或取消后旧结果失效 |
| Codex 适配 | 本地任务索引、实时绑定校验、发送与完成答案 | 不含私人默认编号；只有明确任务能发送；未知回执保留记录，不自动重发 |
| 本地语音输入 | 唤醒检测、录问题、人声检测与中文转写 | 无声音不发送；停顿结束录音；草稿可修改后发送 |
| 回声处理 | 采集与播放参考、设备能力检查、朗读中唤醒 | 必须确认实际播放路由与可用 AEC；自身朗读不能当成用户唤醒；失败时明确降级 |
| 朗读 | 清理非语音内容、选择声音与速度、缓存回应、播放取消 | 预览元数据和代码不读；完整答案保留；所选在线服务只接收朗读文字 |
| 配置和发布 | 原子保存偏好、启动入口、依赖清单、诊断与说明 | 保留现有用户配置；发行内容排除任务、录音、发送账本和个人状态 |

## 第一批设置

- 连接：本机任务刷新、目录筛选、任务下拉、确认连接、打开当前任务。
- 声音：已验证可用的台湾女声和其他声音、速度档位、短句试听、自动朗读。
- 语音：唤醒开关、手动录音自动发送开关、明确的麦克风和状态提示。
- 外观：六种声波、大小、置顶、字幕、位置重置；保存后重启恢复。
- 对话：最新完整答案、识别草稿、开始／结束说话、发送、停止与重读。

## 实施顺序

1. 整理可恢复的源码和配置备份，保留用户当前任务。
2. 并行完成桌面界面、无私人默认值的任务连接、AEC 能力及真实采集验证。
3. 接入配置、声音与速度、状态显示、托盘生命周期，提供可双击启动的程序入口。
4. 跑回归和原生界面渲染检查，验证任务绑定、取消、声音过滤、隐藏恢复与退出释放。
5. 在本机启动新版并检查配置保留、正确绑定、真实麦克风与朗读；声学打断单独验收。
6. 整理使用说明、依赖与当前兼容范围。第二台干净电脑和对外发布不冒充已完成。

## 验收

| 场景 | 通过标准 |
| --- | --- |
| 首次无绑定 | 能列真实本机候选；没有默认投递目标；明确选择并实时校验后连接 |
| 固定任务 | 所选任务名称和目录清楚；切换 Codex 界面不改变绑定；发送回执未知不会重发 |
| 外观和窗口 | 六种样式可切换；右键可用；隐藏恢复保持语音状态；设置关闭不退出；位置在可见屏幕内 |
| 普通操作 | 拖动、选外观、调下一段语速、打开设置和修改草稿都不意外打断当前朗读 |
| 语音收发 | 停顿结束问题；一次发送；收到同一任务最终答案并朗读；文字仍可查阅 |
| 朗读过滤 | 预览代码、路径、网址及代码块不被逐字读出，中文操作说明保留 |
| 语音打断 | 用户在外放朗读中唤醒可停读；助手自己说出唤醒词不触发；保留后续问题开头 |
| 退出与重启 | 释放麦克风和播放器；下次恢复用户选择；不重复发送或重播历史 |

每项验收记录区分纯函数测试、替身状态测试、真实组件测试与声学实测。软件 AEC 或设备不支持时，记录具体失败原因，继续交付其余可工作的功能，保留问题以便完成音频升级。
