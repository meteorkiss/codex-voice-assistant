# 0.7.0 连续对话实现与验证

日期：2026-09-29。状态：程序候审记录。代码实际版本仍为 0.6.18；本文不表示独立审核、总控裁决、用户验收、部署或正式发布完成。

## 实现范围

- `SecretaryConversation.ps1` 管理 `off/listening/transcribing/thinking/speaking/paused/error` 状态、有限会话、独立对话显示、候选快照、本地确认、真实任务复核和工作回执。
- `secretary_model_client.py` 提供有界 OpenAI-compatible Chat Completions 客户端。仅 HTTPS 或 loopback HTTP；Bearer 值只按确切环境变量名读取；禁止跨源重定向；无自动重试；严格 JSON Schema。
- `NoWakeConversation.ps1` 只把显式开启的连续对话接到现有 AEC 分句与本地 ASR。旧 `observe/context` 不再是可启动模式，设置 schema 9 启动时一律迁移为 `off`。
- 设置页提供端点、模型、鉴权方式、凭据环境变量名、文本发送同意、在线朗读同意、空闲时限和轮数上限。连续会话本身不跨启动恢复。
- 字幕区新增独立秘书记录和暂停/继续入口；原 Codex 回答、草稿和 `autoRead` 设置保持独立。
- 动作只允许 `switch_task` 与 `delegate_work`。任务 ID 只留在 PowerShell 内存快照；模型 worker 和 HTTP 请求只得到单轮随机键与显示名。
- 确认快照绑定 session、conversation generation、proposal turn、随机 snapshot ID、45 秒过期、原 binding generation、精确工作文字及候选映射。确认只消费一次。
- 执行动作前再次 live read。切换走统一绑定提交；交办再走唯一 `Send-Text`/`PendingSends` 路径。只在 `accepted` 后显示交付成功；`unknown` 显示核对提示并保留防重派状态。

## 本地验证

已取得的新鲜结果：

- 模型客户端：11 项通过。
- 连续对话状态机：60 项通过。
- 连续对话设置/依赖声明：16 项通过。
- 桌面布局：127 项；Dispatcher：18 步；桌面控制器：22 场景；播放/打断：344 项，均通过。
- 基础设施：100 项通过，包含只清理旧 run 中精确命名的连续对话临时文字，不触碰当前 run、相似文件或持久回执。

覆盖包括：无同意/端点/模型/凭据时零网络；密钥值、路径、任务 ID 不进入请求或结果；loopback 无鉴权；不安全远端 HTTP、跨源跳转、请求/响应超限、超时、截断、坏 JSON 和坏 schema fail closed；候选标题作为不可信数据；随机键不可由 ID/标题推导；候选缺标题、重复、非本机或超过 40 项时动作禁用；快照被篡改、跨 session/generation/turn、过期或绑定变化时拒绝；确认不可重放；live 目标改名/归档/保存失败时无成功话术；交办精确原文、accepted/unknown 分流；TTS 同意关闭仍显示；暂停、空闲、总时长、轮数和停止朗读不复活旧回调。

额外用当前系统 Python 尝试旧 `test_bridge` 与 `test_task_matcher` 共 116 项，其中 33 项在同音路径导入 `pypinyin` 时因该解释器缺少项目运行依赖而报错；该轮不计通过，也没有临时安装依赖或复制个人 `runtime`。本轮未改 `codex_bridge.py`/`task_matcher.py`，对应源码工作树缺运行时仍按既有交付边界记录。
