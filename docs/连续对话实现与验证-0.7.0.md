# 0.7.0 连续对话实现与验证

日期：2026-09-29。状态：产品候选已通过独立内部审核。代码实际版本为 0.7.0；本文不表示用户验收、部署或正式发布完成。

## 实现范围

- `SecretaryConversation.ps1` 管理 `off/listening/transcribing/thinking/speaking/paused/error` 状态、有限会话、独立对话显示、候选快照、本地确认、真实任务复核和工作回执。
- `secretary_model_client.py` 提供有界 OpenAI-compatible Chat Completions 客户端。仅 HTTPS 或 loopback HTTP；Bearer 值只按确切环境变量名读取；禁止跨源重定向；无自动重试；严格 JSON Schema。
- `NoWakeConversation.ps1` 只把显式开启的连续对话接到现有 AEC 分句与本地 ASR。旧 `observe/context` 不再是可启动模式，设置 schema 9 启动时一律迁移为 `off`。
- 设置页提供端点、模型、鉴权方式、凭据环境变量名、文本发送同意、在线朗读同意、空闲时限和轮数上限。连续会话本身不跨启动恢复。
- 字幕区新增独立秘书记录和暂停/继续入口；原 Codex 回答、草稿和 `autoRead` 设置保持独立。
- 动作只允许 `switch_task` 与 `delegate_work`。任务 ID 只留在 PowerShell 内存快照；模型 worker 必须由调用方传入单轮 opaque 键与显示名，缺快照时 fail closed，不再读取任务桥。
- 确认快照绑定 session、conversation generation、proposal turn、独立 confirmation turn、随机 snapshot ID、45 秒过期、原 binding generation、动作/候选键/真实目标/标题/精确工作文字及候选映射，完整指纹在确认和执行前都复核。确认只消费一次。
- 执行动作前再次 live read。切换走统一绑定提交；交办再走唯一 `Send-Text`/`PendingSends` 路径。只在 `accepted` 后显示交付成功；`unknown` 显示核对提示并保留防重派状态。
- 模型 prose 仅进入明确标源的“模型答复（未执行操作）”行，朗读先加本地免责来源提示；确认与真实回执仅写独立“声伴状态”，不进入模型历史。
- 迟到回执总会更新工作账本和可见状态；在 paused/off/error、新 session 或旧 generation 下不排 TTS、不改 phase、不恢复 capture。
- 跨重启或切换绑定时，权威状态从当前真实任务的 `PendingSends` 恢复；未知锁会在 worker 启动、模型完成回调和 UI/TTS 渲染三层阻断模型文本，不自动清锁或重派。
