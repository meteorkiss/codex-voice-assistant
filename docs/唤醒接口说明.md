# 本地唤醒接口

唤醒使用专门的中文关键词模型。`src/WakeListener.cs` 在当前 PowerShell 进程内采集 16kHz 单声道音频，经内存管道交给 `src/wake_worker.py`；待机音频不写文件，也不上传。模型约 5MB，位于 `runtime/models/wake`。

Windows 固定语法识别器在近音词上出现高置信误触，最终版本采用 sherpa-onnx 的中文 KWS 模型。`System.Speech` 已不是本接口的依赖。

## 配置与状态

```powershell
Add-Type -Path (Join-Path $projectRoot 'src/WakeListener.cs')
$wake = New-Object WakeListener
$wake.Configure(
    (Join-Path $projectRoot 'runtime/python/python.exe'),
    (Join-Path $projectRoot 'src/wake_worker.py'),
    (Join-Path $projectRoot 'runtime/models/wake'))
$wake.Start('你好声伴')
```

`Start` 和 `Stop` 都不阻塞界面。`Start` 立即设置 `IsListening=true`，后台加载模型并打开麦克风后才设置 `IsReady=true`。本机测试准备约 2 秒，界面可在此阶段显示“正在准备唤醒”。

`ActivationVersion` 每次成功唤醒递增一次，`LastKeyword` 保留匹配的短语。唤醒后监听器自行停止。调用方须等待 `IsListening=false` 且 `IsStopping=false`，再等 MicGuard 至少一次新扫描确认无活动麦克风，才能播放“在”。声音播完后再启动问题录音。

`Stop()` / `Cancel()` 取消本轮监听，取消后的结果不产生唤醒。关闭窗口时调用 `Dispose()`。跨轮次输出按内部版本隔离，旧工作进程迟到的消息不会触发新一轮。

`KeywordThreshold` 默认 `0.35`，越高越难触发；`MinimumConfidence` 是同一设置的兼容名称。本次降低门槛依据低音量及加噪离线样本，真实用户的唤醒效果仍需观察，详见 [唤醒漏检排查](唤醒漏检排查.md)。KWS 不提供每次检测的概率，因此 `ConfidenceAvailable=false`、`Confidence=NaN`，不能用该字段作为唤醒条件。界面应比较 `ActivationVersion`。

`GetSnapshot()` 返回上述状态及 `Error`、`AudioLevel`（0–100）、`ActivatedUtc`。`IsReady` 为真时，麦克风会话归属当前 PowerShell 进程，方便与外部麦克风使用区分。

## 测试入口与边界

`StartWaveFile(phrase, path)` 和 `StartWaveBytes(phrase, bytes)` 只从内存解码 16kHz、单声道、16位 PCM WAV，不打开真实麦克风。默认正例位于 `tests/fixtures/wake/positive-taiwan-chen.wav`，短语为“你好声伴”。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-WakeListener.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-WakeCancellation.ps1
```

真实麦克风生命周期测试单独执行 `tests/Test-WakeMicrophone.ps1`；它会短暂打开麦克风，但不保存音频。首次验证：停止调用约 1ms 返回，56ms 关闭设备，MicGuard 在 87ms 内确认释放。

11 条固定语音与噪声样本通过：3 种台湾或大陆女声的正例，以及普通句、近音词、半句、回应句、粉红噪声和静音等 8 条反例。早取消后立即重启的 3 轮检查也通过。这组测试不代表对真实口音、远距离、电视声音或所有近音词的准确率保证。默认建议保留四个字的完整短语；仅两字的名字更容易与普通说话重合。

Python 依赖为项目内的 `sherpa-onnx`、`numpy` 和 `pypinyin==0.55.0`。模型来源与 SHA256 记录在 `runtime/models/wake/manifest.json`。官方资料：

- https://k2-fsa.github.io/sherpa/onnx/kws/pretrained_models/index.html
- https://k2-fsa.github.io/sherpa/onnx/kws/index.html
