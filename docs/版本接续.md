仍缺少的真人、设备、异机安装、发行许可和远端检查分项记录，不因开发任务归档就标为通过。旧纯 Git 导出回归命令曾被自动审批阻止，不能重试或绕过；普通 CI 或源码布局检查的结果如实单列。

## 下一版：0.6.18 输入输出设备设置

范围对应功能总表 N11，先实现一个可验收的小范围：列出可用输入与输出设备，允许用户明确选择或恢复系统默认，并把回声参考端点与实际朗读输出保持一致。设备不存在、断开或保存失败时回退到原选择，不静默改用另一个同名设备。

## 后续选题与收口

0.6.17 完成后，从功能总表中尚未实现且前置条件具备的需求选下一项，推荐先处理明确设备设置、模型预设或指定项目新建；完全免唤醒及三档灵敏度要先具备可校准的判定器，不能用简单关键词冒充。仅支持已记录范围，微信保持暂不开发。
