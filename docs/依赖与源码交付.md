## 校验与分发待办

JSON 清单包含 12 项模型、说明和音频文件的路径、大小及 SHA-256，可在项目根目录只读复核：

```powershell
$inventory = Get-Content .\tools\runtime-inventory.json -Raw | ConvertFrom-Json
foreach ($artifact in $inventory.artifacts) {
    $file = Get-Item -LiteralPath $artifact.path -ErrorAction Stop
    $hash = (Get-FileHash -LiteralPath $file.FullName -Algorithm SHA256).Hash
    if ($file.Length -ne $artifact.bytes -or $hash -ne $artifact.sha256) {
        throw ('依赖不一致：' + $artifact.path)
    }
}
.\runtime\python\python.exe -B -m pip check
```

本机 NAudio 附有 MIT 文本，唤醒模型 README 标注 Apache License 2.0；SenseVoice 的本机 LICENSE 仅是另一个项目许可页面的指引。以上是本地文件中的记录，不能替代对相应模型、权重与资源具体分发条件的核验。Python、Python 包、模型及七个预生成回应音频的完整第三方声明仍需补齐；项目自身尚未选择公开许可证。本轮不据此生成或发布包含第三方依赖的安装包。
