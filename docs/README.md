## 文档状态约定

- “已实现”只指代码路径存在；离线回归、真人声学、真实任务往返、异机安装和公开发行分别记录。
- “候审”只指程序提交了可审候选；不等于审核通过、用户验收、上传或部署。
- “计划”与目标版本只用于排期；只有总控给出单项计划且用户批准后，程序才开始实现。
- 只有用户明确说“收口”才触发版本总结、下一版本总控任务和本版本已完成任务归档。
