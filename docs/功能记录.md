匹配逻辑与切换流程使用隔离数据及桥接替身验证。另对“高斯坡建”做过一次真实本机只读搜索，获得唯一同音候选；没有因该测试修改实际绑定或向目标发消息。不同人的口音、含糊名称和多音字仍需要实际试用反馈，不能保证所有转写错误都能匹配。

查找只读取任务列表。切换前继续沿用已有 Codex 读取校验；成功后新问题沿用目标任务自己的模型、工作目录与权限。声伴不会同步改变 Codex 前台页面。
