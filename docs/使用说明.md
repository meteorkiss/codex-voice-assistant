# 声伴 · Codex 语音助手 v6

2026-09-09，v6 / 0.6.13。声伴负责听、显示文字和朗读；你明确绑定的现有 Codex 任务继续负责思考和操作。当前是本机可运行的桌面程序，尚未公开发布，也未在第二台纯净电脑完成验证。

0.6.12 的分组、对话管理与暂停／继续朗读说法见 [本地管理口令](本地管理口令-0.6.12.md)。

## 第一次打开

1. 打开并登录你自己的 Codex，保留想继续的任务。
2. 双击项目根目录的 **“声伴.exe”**。启动器不会弹出终端；请保留旁边的 `src`、`assets` 和 `runtime`，不能只复制 exe。
3. 在设置左侧选择“连接”，再点“刷新”。可先用“工作目录”筛选，再从“目标任务”下拉中选一个，点击 **“连接所选任务”**。
4. 查看“当前绑定”的任务名称和实际工作目录。只有实时读取校验成功才会绑定；未选择时不会默认发送到最近任务。
5. 在设置左侧“声音”选择声音和语速，可以点“试听声音”。开启“语音唤醒”后，等待状态显示待机，再开始说话。唤醒准备通常约两秒，具体以状态显示为准。

0.6.13 起，手动连接前如有草稿或待发送内容，会保留文字并提示先处理。连接等待期间编辑文字、改变任务选择、开始新的录音、刷新列表或取消操作，都会使旧连接请求失效；即使后来删空输入或重新选回原选项，也需重新点击连接。连接或保存失败保留原任务。

目录只用于筛选已有任务，不会修改它的工作目录。刷新列表、改变筛选、只选中下拉项都不会切换已绑定任务。手动连接请点击连接按钮；0.6.6 起也可使用下面的语音切换口令。任务和偏好会保存，下次启动重新校验；如果原任务不可用，重新打开设置选择。

声伴不会随着 Codex 界面切换而自动换任务。它不额外指定模型或权限：原任务使用 GPT‑6，就继续由该任务的模型回答。修改模型、处理权限确认和查看工作文件仍在 Codex 中操作。0.6.7 支持下面的语音新建口令；新任务使用 Codex 配置的默认模型，不复制旧任务的模型设置。快速／深度模式预设尚未提供。

## 平时怎样说话

开启“语音唤醒”后，说 **“你好，声伴”**，听到回应“在”再说问题。说完停顿约两秒，程序会停止录音、在本机转成文字，并向当前绑定任务发送一次。录问题后八秒没有人声会返回待机，不发送空内容。

从 0.6.3 起，可在“设置 → 声音 → 唤醒词”修改文字，再点“保存”或按回车；“恢复默认”改回“你好，声伴”。支持 2—16 个汉字，建议使用 4—6 个常见汉字，例如“你好小伴”。可以用空格或逗号分隔，不支持数字、英文和表情。保存后只重载语音唤醒，不必重启整个软件；再次启动仍使用已保存的词。常见自定义词已验证可加载，生僻字、多音字或特殊读法的实际唤醒效果需试用确认。

为了保留正在听或录的内容，录音、识别、发送和朗读期间不能保存新唤醒词，输入框里的修改会保留并显示提示；等本轮结束或先停止朗读再保存。编辑输入框但未保存不会切换唤醒词。

Codex 完成后，答案显示在字幕区；“自动朗读回答”开启时也会读出来。0.6.6 起，单独列出或附在句尾的参考链接（例如“体积示例”“训练与导出说明”）以及脚注不朗读；正文中必需的链接文字仍保留。屏幕上的完整答案不变。唤醒录音的自动发送不受“手动录音停顿后自动发送”开关影响。需要长时间停顿思考或先核对指令时，改用手动录音更合适。

v6 已接入朗读期间的唤醒检测：回声处理和设备状态就绪时，可以在答案朗读中喊“你好，声伴”，程序会停止旧朗读、回应，再接收问题。它不会因此取消 Codex 正在执行的任务，停止的旧答案也不会自动续读。

**这项语音打断仍有验证边界：**本机采用固定播放设备与 Windows VoiceCaptureDSP 回声处理；扬声器连续播放三次“你好声伴”的对照测试中，原始麦克风音频能触发唤醒，回声处理后的音频没有误唤醒。真人同时压着答案说话、不同距离和音量的实际效果尚未验证，不能据此保证所有房间和设备都能可靠打断。唤醒不可用时会显示提示，可用“开始说话”或“停止朗读”手动控制。

设置中的“朗读时也可唤醒（回声消除）”可以单独关闭；关闭后改为轮流听说，答案读完再恢复唤醒。下方状态会显示回声处理是否就绪或设备错误。

关闭设置中的“语音唤醒”，或托盘中的“免点击语音唤醒”，会停止常驻唤醒监听。输入框里有未发送文字、正在发送、未连接或上次发送待核对时，会暂缓唤醒，避免覆盖文字或重复发送。

0.6.8 会忽略已确认退出进程遗留的麦克风占用记录，避免重启后误等旧程序释放。其他应用确实在录音时会明确提示“语音唤醒已暂缓”；结束该应用的录音后再唤醒。

0.6.7 调低了唤醒关键词的检测门槛，已有低音量与加噪文件样本有所改善，但没有验证真人唤醒准确率。监听启动约两秒及恢复时的 800 毫秒冷却仍可能形成空窗；等“正在准备语音唤醒”的提示结束，再喊唤醒词；听到“在”再说问题。原因、证据和限制见 [唤醒漏检排查](唤醒漏检排查.md)。

## 直接说出设置指令

按原来的方式说“你好，声伴”，听到回应后说一句设置指令，停顿约两秒。声伴会在本机识别指令、修改并保存设置，不需要等待 Codex，也不用再安装大语言模型。手动录音时，先识别再点击发送，同样会执行本地设置。

| 可以说 | 效果 |
| --- | --- |
| 换台湾女声；换成晓雨 | 切换声线，反馈使用新声音 |
| 语速慢一点；语速快一点；恢复正常语速 | 在现有四档之间调整 |
| 置顶；取消置顶 | 同步悬浮窗、字幕、设置和右键开关 |
| 显示字幕；隐藏字幕 | 切换字幕显示 |
| 隐藏悬浮声波；显示悬浮声波 | 隐藏或恢复悬浮图形 |
| 打开设置 | 打开设置窗口 |
| 关闭自动朗读；开启自动朗读 | 切换之后的回答朗读 |
| 换成柔光环；换成流动声线 | 切换已有声波样式 |
| 停止朗读 | 停止现有语音和队列，只显示文字确认 |

每次说一个明确操作，例如“给我换个女生，台湾女生”。开始语音录入会先停止旧朗读；“停止朗读”和“关闭自动朗读”也会清掉语音队列，不再读一段确认。其他设置保留已到达的回答；麦克风与回声处理就绪时，会用简短语音反馈，沿用现有的保护和微软在线朗读服务。暂时不能安全播放时显示文字确认。命令反馈不覆盖 Codex 上一条完整回答。

“不要换台湾女声”“为什么要取消置顶”以及引用指令、多个要求混在一起等内容不会直接改设置，仍交给 Codex 处理。当前识别的是常用说法，未匹配的话也继续发送给 Codex。断开任务时可以在输入框输入本地指令并点击发送；语音唤醒仍沿用已有连接条件。

## 用语音切换任务

唤醒声伴后，单独说 **“切换到高斯坡建任务”**，也可以说“帮我切换到某某任务”。名称以你的实际任务标题为准。声伴查找本机任务列表；没有文字匹配时，至少三个汉字的名称会再尝试同音匹配，因此部分转写同音错字也能找到。

- 只有一个明确结果：实时读取并确认可连接后，保存声伴的绑定，读出“任务已切换”。之后的问题发给新任务。
- 有多个结果：打开设置的连接页，显示原始任务标题，最多列出五个；说“选择第二个任务”之类的序号，或手动选择并点击连接。选择有效期为九十秒，过期请重新说名称。
- 想放弃：说“取消切换”。没找到或读取失败时仍保留原任务，可以换更具体的关键词。序号也可以简说“选择第二个”。

语音查找覆盖本机候选任务，不受设置中的工作目录筛选限制。它只改变声伴绑定，不会强制切换 Codex 前台页面，也不会新建任务。短名称、不同词义、生僻字、多音字和不止同音字的识别错误可能需要重新说准确标题。没有候选列表时，“选择第二个任务”按普通输入处理。

切换是单独的一条操作，请等成功提示再说新问题；不要把“切任务并处理某事”合成一条。搜索和读取各最多等待三十秒；新录音、草稿变化、手动刷新或改绑定会取消旧的读取结果。发送仍待回执或核对时，会提示先处理发送状态。已经识别为切换的口令即使失败，也不会作为问题送给 Codex。

## 用语音新建任务

先连接一个本机 Codex 任务，再单独说一条新建口令：

| 可以说 | 创建位置 |
| --- | --- |
| 新建一个任务；新建一个聊天 | 新的独立聊天，不归入某个已保存项目 |
| 新对话；新任务；新聊天 | 新的独立聊天，可带“吧／啊／呀”等句末语气词 |
| 帮我弄一个新对话；给我开个新任务 | 新的独立聊天，口语动词“弄／建／开／搞”后需要说“新” |
| 新建一个叫周末安排的任务 | 新的独立任务，并使用指定名称 |
| 在当前项目新建一个任务 | 当前绑定任务对应的已保存本机项目 |

“当前项目”以声伴当前绑定任务的实际目录为依据，不以 Codex 前台页面或设置中的目录筛选为依据。只有唯一匹配的已保存本机项目才能创建；没有匹配、匹配不唯一或项目状态不完整时会说明原因，不会猜另一个项目。Git 项目会创建独立工作树，非 Git 项目使用项目本地目录。这项操作不把已有聊天移动到项目中。

请等到“新任务已创建并连接”再说新的问题。声伴先获得真实任务编号、实时读取校验并保存绑定，之后才发送到新任务；它不会强制打开 Codex 前台页面。新任务使用 Codex 配置的默认模型与思考设置，**不会自动继承原任务选定的 GPT‑6 或推理强度**；需要指定时，在 Codex 中打开新任务调整。

- **连接刚才的新任务**：继续查询原请求，或重新校验已创建任务的连接；不会再创建一次。
- **放弃连接新任务**：停止自动连接并允许继续向当前已绑定任务提问；已经创建的任务仍保留，已派发的创建也不会被取消。

创建结果不确定时，声伴保留请求记录，不会通过重说或重启自动重复创建。自动查询最多持续三十秒，随后暂停并提示核对或恢复。此时新的问题会留在输入区，不会送给旧任务。先处理或保留草稿，再使用恢复／放弃口令；有未发送草稿、录音或发送等活动时，不会强行更换绑定。

开始新的录音、修改草稿、手动操作连接或退出，会使原来的自动连接失效；迟到回执仍记录新任务编号。明确手动切换到已有任务或说“放弃连接新任务”，可解除向原任务发送的保护。仅刷新列表或改目录筛选不会解除保护。

如果 Codex 只返回临时客户端编号，当前接口无法把它自动解析成可连接的真实任务编号。请在 Codex 中核对已创建的任务，再到声伴设置刷新并手动连接；重复查询不会解决这个限制。保存新绑定失败时，也保留原任务与已创建编号，恢复连接不会重复新建。

新建是单独的一条操作；把“新建并执行某事”合成一句，不属于目前的直接新建口令。程序在聊天发送前匹配整句，命中后直接调用创建接口，无需让旧任务中的模型理解口令。“比如说新对话”“新任务是什么意思”“不要新建”都不会命中；单说“创建”缺少对象，也不执行创建。

## 手动录音与文字

从托盘选“开始说话”，会显示声波并打开展开的字幕输入区，再停止旧朗读并录音；也可以先显示字幕，点“展开与输入”，再点“开始说话”。

- 说完直接点“发送”：结束录音、识别并发送。
- 想先检查：点“结束录音”，等文字出现后修改，再点“发送”。识别需要短暂等待，当前不逐字转写。
- 放弃本次录音：点“取消录音”。只停止声音：点“停止朗读”。

“手动录音停顿后自动发送”默认可保持关闭；开启后，手动录音也会在检测到人声并停顿约两秒后自动发送。

遇到“发送状态待确认”时，文字和请求记录会保留，程序不会自动重发。先在 Codex 检查是否收到，再从托盘选择“已在 Codex 核对上次发送”并确认，才能解除当前任务的发送锁。切换任务或重启不会清掉其他任务的待核对记录。

## 桌面声波、字幕与设置

桌面只常驻透明声波。按住周围声波拖动；右键打开设置、置顶、字幕、停止朗读或隐藏声波。中央两个按钮分别控制播放／暂停和结束朗读。右下角托盘图标左键打开设置，右键打开完整菜单；图标可能位于 Windows 的隐藏图标区域。

| 操作 | 行为 |
| --- | --- |
| 设置 → 外观 → 声波样式 | 可选流光环、柔光环、微粒环、细线环、律动音柱、流动声线 |
| 大小与置顶 | 调整声波大小；置顶开关与右键、托盘同步。重置悬浮位置可找回移出屏幕的窗口 |
| 显示字幕与输入 | 收起时显示答案；“展开与输入”显示输入框和录音、发送按钮，再点“收起”恢复简洁字幕 |
| 关闭设置或字幕 | 只隐藏对应窗口，不退出助手；关闭字幕按钮也会更新字幕开关 |
| 隐藏悬浮声波 | 隐藏声波及字幕，录音、唤醒与朗读按原状态继续；从托盘恢复 |
| 退出语音助手 | 真正结束监听、录音和播放；已派发的发送和创建进程会继续完成回执记录，避免重复操作 |

打开设置、刷新任务列表、换样式、调大小、换声音或语速、拖动、隐藏窗口都不会打断当前朗读。明确停止、开始录音、发送新问题、切换到另一个任务和退出会停读。其他程序实际启用麦克风时，也会暂停相关听说活动，避免答案被录进去。

声波右键菜单和托盘提供“暂停朗读”；字幕顶部也有“暂停”。暂停后同一按钮变为“继续”，可以从暂停的位置接着听，后续已排队的段落也保留。暂停不等于停止：“停止朗读”会结束当前音频并清队列，之后用“重读”从这条答案开头再听。准备语音但还没开始播放时，暂停按钮不可用。继续播放仍会检查麦克风与回声处理状态；开始新一轮语音提问会结束旧朗读。

0.6.5 声波中央有两个半透明按钮。左侧双竖线表示暂停，三角形表示继续或播放上一条回答；右侧方块表示结束朗读，也可取消尚在准备中的语音。两个按钮平时很淡，鼠标移上去会略明显；没有相应操作时变淡并禁用。按钮可右键打开原菜单；拖动位置仍按住周围声波。结束朗读不取消 Codex 正在处理的任务，也不清除屏幕上的答案。

已按试用反馈移除空格播放快捷键；使用中央按钮、右键菜单或字幕上的按钮操作。Windows 控件自身的键盘行为保持正常。

声波跟随真实音量：朗读时读取声伴正在播放的音频，收音时读取麦克风；朗读优先，避免同时运行的回声消除麦克风覆盖播放音量。暂停后收敛到安静状态，待机保留很轻的流动。0.6.7 增强低音量下的可见形变，实际扬声器音量不变。它表现的是声音强弱，不是逐频率的实测频谱。

开启置顶后，声伴在显示窗口及切换到其他软件时恢复上层位置，不抢走原软件的输入焦点。自家设置与右键菜单仍显示在悬浮窗上方。该功能用于普通桌面窗口，无法保证覆盖独占全屏程序或 Windows 安全桌面。

## 声音与语速

设置中提供七种声音：

| 语言 | 可选声音 |
| --- | --- |
| 台湾中文 | 女声晓臻、女声晓雨、男声云哲 |
| 普通话 | 女声晓晓、男声云希 |
| 英语 | 女声 Jenny、男声 Guy |

语速提供 0.8×、1.0×、1.2×、1.5× 四个档位，实际效果由语音服务决定。换声音、语速从后续合成的语音生效；要马上听新设置，可点“试听声音”，这会明确停止当前朗读并播放试听句。

“自动朗读回答”只控制之后到达的新答案；关闭它不停止当前播放或已排队语音，重新开启也不自动重读历史。需要重读时，用字幕区或托盘的“重读上一条回答”。

朗读会跳过预览标记、代码块、行内命令、链接地址和文件路径，链接保留说明名称，GPT‑6 等短名称正常朗读。完整答案仍保留在字幕和 Codex 中；只有代码或预览的回答可能没有可朗读内容。

## 连接、音频与数据

桌面 Codex 连接仍是实验适配，尚未嵌入官方界面。任务候选来自本机只读索引，选择后经实时接口校验；目前只接本机 Codex 主任务，不把远程、WSL 或子智能体任务当作已支持目标。未找到连接时，先在 Codex 打开任务，再回设置刷新；不要复制其他电脑的任务编号或登录资料。

唤醒检测和回声处理在本机进行，待唤醒音频只在内存中处理，不保存、不上传。问题录音由本机 SenseVoiceSmall 与人声检测模型识别，临时问题音频在处理后清理；发送给 Codex 的是文字。

朗读使用已经同意的微软在线声音，会把要读的文字发送给微软，需要联网。切换声音不会更换负责回答问题的大模型。

当前播放设备会与回声参考保持一致。切换默认扬声器或拔插设备后，如声音或唤醒异常，先在 Windows 选好设备，再退出并重新打开声伴；尚未提供应用内的设备选择列表。

`data` 保存设置、发送状态、任务创建记录及运行临时文件；`runtime/python`、`runtime/audio` 与 `runtime/models` 保存本地依赖；`work` 保存测试产物。移动项目时保留完整目录，随后重新检查本机 Codex 任务及设备。现有 exe 只是启动入口，不是可独立分发的安装包；不要把个人 `data` 或账户资料装进公共包。

本机已验证任务发现与指定任务只读校验、界面与状态机回归、设置保存、任务创建的隔离接线、语音组件以及上述回声对照实验。0.6.7 已加载并确认原绑定、偏好、回声采集和置顶保留；这不等于已向真实 Codex 创建或发送。第二台纯净 Windows 的完整首次连接、听说和重启恢复仍待验证；测试索引见 [测试说明](../tests/README.md)。
