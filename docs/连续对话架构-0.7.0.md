# 0.7.0 连续对话成品架构

日期：2026-09-29。状态：程序实现规格，基于 `fe7a990d9794692c75af6b0e6cd0755ef722fb35`；不表示真实云、真人声学、部署或用户验收已经通过。

## 本次唯一交付

用户一键开启一个有限、可见、可立即暂停的连续对话会话。声伴复用现有 AEC、`NoWakeCapture`、本地 ASR、字幕和 TTS；每个完整分句先显示在独立秘书对话区，不写入或阻断旧 Codex 工作草稿。秘书可以闲聊、自然澄清，并对切换任务或明确交办提出一次本地确认；只有本地事务取得真实结果后，声伴才报告成功。

本项不新增全双工插话、任务创建/归档/删除、微信/飞书入口、全天背景承诺，也不把模型变成权限来源或工具执行器。

## 信任边界

1. 音频只进入现有本地 AEC、分句和 ASR，不放入模型 HTTP 请求，默认不保留原音频。
2. 首个文本适配为用户配置的 OpenAI-compatible Chat Completions JSON 协议。只允许 HTTPS；`localhost`、`127.0.0.1`、`::1` 的 HTTP 仅供本地服务和合成 mock。兼容协议不等于任何供应商均已验证。
3. 非 loopback 服务首版只支持 Bearer 凭据，并只按用户填写的环境变量名精确读取；不枚举环境变量、不读取既有密钥、不把值写入设置、日志、异常、请求文件、测试结果或仓库。只有用户显式选择 `authMode=none` 且地址为 loopback 时允许无鉴权，仍需配置服务并同意数据发送。
4. 用户须分别同意：向所配置文本服务发送“当前分句转写、少量内存对话、最小任务候选显示名”；以及把秘书回复交给已有在线朗读服务。无模型配置或无文本同意时零模型网络；无朗读同意时秘书回复只显示，不调用在线朗读。既有唤醒和 Codex 回答 `autoRead` 偏好不被改写。
5. 候选标题是不可执行数据：去控制字符并限长。每轮只发送显示名和不可预测 `candidateKey`；不发送 `threadId`、聊天正文、文件内容或路径。列表缺标题、不完整或超上限时动作提案 fail closed。
6. `candidateKey` 只存在于本轮内存快照，绑定 session/turn/snapshot/expiry；模型伪造、过期、跨轮复用或直接返回 raw thread ID 均拒绝。

## 模型输出契约

模型只能返回以下三者之一，且本地再次严格校验，拒绝未知字段、错误类型、截断或拒答：

- `chatText`：普通聊天文字；另外两项必须为空。
- `clarification`：需要用户澄清的问题；另外两项必须为空。
- `actionProposal`：仅含 `action`（`switch_task` 或 `delegate_work`）、`candidateKey`、`workText`；`chatText` 和 `clarification` 必须为空。停止/暂停只接受本地 UI 或既有明确本地口令，不由模型提案，也不代表取消 Codex 工作。

动作提案不能携带“已切换”“已交办”等面向用户的成功话术。畸形动作不会降级成普通工作发送，而是显示本地安全错误并回到可控状态。

## 动作确认与真实事务

模型提出 `switch_task` 或 `delegate_work` 时，声伴创建一次不可变待确认快照：`sessionId`、`conversationGeneration`、`proposalTurnId`、随机 `snapshotId`、`expiresAt`、`originalBindingGeneration`、操作类型、本轮不可预测候选键到本机真实 ID/显示标题的映射，以及确切工作文本。界面显示并按用户朗读同一条本地产生的确认提示（只有朗读同意时才联网朗读）。

- 下一句“是的/确认”等是新的输入 turn，但只消费当前会话中唯一未过期的原 `proposalTurnId` 快照一次，不能修改动作、目标或正文；不会错误要求确认 turn 与提案 turn 相等。
- “不是/取消”仅取消该快照。
- 非确认的新话题或修订、暂停/关闭、超时、候选改名/归档/缺失、原绑定变化使快照失效；确认句自身不会先触发通用“新输入失效”。
- 多项或不明确提案不产生可执行快照，继续自然澄清。“是的”不能授权此前其它、过期或模糊提案。
- 切换成功文字只在同 ID live read、名称一致、未归档且绑定保存完成后由本地产生。
- 委派先完成相同 live read/绑定事务，再复用唯一 `Send-Text` 与 `PendingSends` 账本。只有 `accepted` 才本地报告“已交付”；`unknown` 只报告结果未知并保持防重派锁。

现有强本地明确口令继续走原事务，不为了新说法再增加无穷别名规则。

## 生命周期

可见状态为 `listening / transcribing / thinking / speaking / paused / error / off`。默认关闭；升级时旧 `observe/context` 一律迁移为关闭。会话受空闲时限、最大总时长和最大轮数约束。

`conversationGeneration` 只决定收音、ASR、模型回调和朗读后恢复资格；`work requestId` 与 `PendingSends` 决定已派发工作的唯一回执生命周期。暂停、关闭或取消模型/采集不等于撤销已 `accepted` 工作，也不解除 `unknown` 防重派。

朗读期间暂停收音。只有同一代、仍启用、未暂停/关闭且观察到本次朗读自然结束时才恢复监听；停止朗读、目标切换的旧回调、模型迟到结果或捕获释放超时都不能复活会话。

## HTTP 与容量

单次请求不自动重试。设置连接/读取/总超时，禁止跨源重定向携带凭据；限制转写、历史、候选数量、请求体和响应体。首版把 `response_format.type=json_schema` 作为兼容门槛；供应商不支持时可见失败，不偷偷降级或重试。响应不是 2xx、超时、取消、超限、坏 JSON、坏 schema、未知键或 `finish_reason` 非完整完成均失败关闭本轮动作权限。合成 mock 只证明客户端契约，不代表真实云兼容或隐私政策已经验证。

## 验证边界

自动化仅使用合成文字、状态、PCM/ASR 替身和本地 loopback HTTP mock；不录真实麦克风，不读取真实密钥，不发送真实对话/音频，不操作真实任务或产生付费。真实模型服务、真人连续交谈、在线声音、异机安装与桌面部署分别等待总控裁决和用户集中验收。
